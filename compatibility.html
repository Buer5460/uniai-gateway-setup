官方资料与会员计费边界

Kimi Code API · 会员与额度 · 个人交互使用规则

Qoder SDK 登录 · 模型选择 · Credits

WorkBuddy 第三方应用 · 助理/任务 API · TRAE Work · DuMate

Kimi Code 会员 API 与 Moonshot 按量 API 不是同一计费入口。不同会员档位有不同资格；若用户启用了 Extra Usage，加油包可能在会员额度用尽后扣费。UniAI 不应擅自购买、开启补充额度或切换费用来源。

个人自用工具集成与转售模型服务不同。各用户使用自己的授权，不将任何人的订阅池化或分售；收费分发工具也不自动获得所有平台的商业授权。

正式版必须做到的三个步骤

这是发布验收要求，不是宣布当前工程版已经实现。

01 · 安装

一行命令，环境由软件准备

识别系统与旧安装；自带或自动安装必需依赖；安全迁移配置；失败保留原状态。

02 · 授权

只完成自己的账号授权

识别已授权来源，或者在本机填写官方密钥。页面显示权益来源、真实模型及费用边界。

03 · 使用

回到 ZCode，完成真实任务

自动接入后生成一个实际文件并打开；流式、工具回传和重新打开软件都通过，才算可用。

修复已有电脑：不再让用户反复试错

先确认实际运行的实例。 核对程序路径、数据目录、进程用户和正在加载的 Adapter。不能用开发目录测试代替安装版。
把三层授权分别诊断。 本机控制台会话、ZCode 网关 Key、上游模型授权是三件事。读取格式不兼容应报告 Adapter 不兼容，而不是反复要求登录。
修具体原因，保留原来数据。 不盲目重装、不清库、不连续轮换 Key、不偷偷替换模型。没有可用授权接口时如实保持阻塞。
成功以实际任务为准。 原生 ZCode 得到真实回复、创建并读取本地文件、关闭重开后仍可使用；模型列表 200 和控制台绿色不算替代证据。
