UniAI Gateway

把你本机已有的模型授权，变成一个 OpenAI 兼容的本地网关和一个控制台。

1

已经安装过？点一下就能用

按钮调用的是本机 UniAI.exe（安装出来的那一份 Runtime）， 浏览器只是转达，不会上传任何东西。首次点击 Windows/浏览器可能问“要打开 UniAI Gateway 吗”，点允许即可。

打开 UniAI 备用：打开 http://127.0.0.1:8935/console

它会自己在后台起网关、用本机登录态取得管理凭据、按这台机器的账号生成模型目录，然后打开已登录的控制台。

2

第一次使用：复制这一行

粘贴到 PowerShell（开始菜单搜“PowerShell”，Windows 11 里是“终端”的 PowerShell 标签页），回车。 不需要预装 Python / Node / Git，也不需要管理员权限。

[Net.ServicePointManager]::SecurityProtocol='Tls12'; iwr -Uri https://github.com/Buer5460/uniai-gateway-setup/releases/download/v0.8.0/UniAI-Setup-0.8.0-windows-x64.exe -OutFile $env:TEMP\UniAI-Setup.exe -UseBasicParsing; Start-Process -FilePath $env:TEMP\UniAI-Setup.exe -ArgumentList '--silent','--dir',"$env:LOCALAPPDATA\UniAI Gateway",'--launch' -Wait

这一行做三件事：下载安装包 → 静默安装到 %LOCALAPPDATA%\UniAI Gateway（端口自动挑第一个空闲的，从 8935 开始）→ 装完直接打开控制台。

实测支持范围与限制

已实测通过 Windows 11 中文版，标准用户权限（无需管理员）
静默安装 / 向导安装 → 桌面、开始菜单、开机自启入口 → 卸载全部可逆
uniai://console 协议唤起：后台启动 + 自动取得本机凭据 + 按本机账号生成模型目录 + 打开控制台（约 17 秒）
安装完成后可不依赖 Python / Node / Git 独立运行
未验证 标注 Windows 10 及更早版本、非中文系统界面、ARM 机型、企业策略/杀软拦截注册表写入的场景
网页按钮在 Safari / Firefox 下唤起协议的行为（Chrome / Edge 已实测）
已知限制 网关只监听 127.0.0.1，不给局域网或公网访问；模型目录由目标机器上的客户端配置与本机登录态现场核验生成，安装包本身不含任何模型清单或密钥
卸载可在“设置 → 应用”里完成，数据与模型目录默认保留，可勾选清除
