打不开，或不能回复怎么办？

还没安装：先下载安装包。「打开 UniAI」只能唤起已经安装的程序。

装好了但不能回复：先看支持情况。当前 WorkBuddy 兼容问题不能通过反复登录、重装或换 Key 解决，请保留原有配置。

下载失败或被安全软件拦截：停止操作，不要关闭安全防护。安装命令会显示失败原因和日志位置。

版本、系统要求与技术说明

当前安装包：0.8.0 / installer-fix.2，仅供工程试用。应用自带必需的 Python 运行库；当前版本不需要额外安装 Node 或 Git。下载需要能访问 GitHub。

支持目标为 Windows x64；ARM 和 32 位不支持。目前验证环境是 Windows Server 2022 的隔离用户目录，不是所有 Windows 10/11 空白电脑，也未证明原生 ZCode 的完整文件任务通过。

安装脚本发现已有安装时会复用，不会无条件升级或修复已有账号问题。安装包不附带你的平台账号或模型额度，不会替你购买套餐。
